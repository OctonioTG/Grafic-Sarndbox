## Credits

This project is an add-on for **SARndbox**, the Augmented Reality Sandbox software created by
[Oliver Kreylos](https://web.cs.ucdavis.edu/~okreylos/ResDev/SARndbox/) at UC Davis (KeckCAVES).
SARndbox does the 3D scanning, projection and water simulation; this project reads the terrain
it saves and adds the geological analysis and the web dashboard.

It is a separate program: it does not include or modify SARndbox code. To use it you need a
working AR Sandbox with SARndbox 2.2 or newer.

- SARndbox: https://web.cs.ucdavis.edu/~okreylos/ResDev/SARndbox/
- Source code: https://github.com/KeckCAVES/SARndbox
